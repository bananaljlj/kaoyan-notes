## 二、把整节想成三个问题

```text
设备准备好没有？  -> CPU 反复查（程序查询），或设备发中断请求
每次谁搬数据？    -> 查询/中断方式：CPU 经接口搬；DMA：控制器与主存直接传
传完谁收尾？      -> 普通中断：CPU 的中断服务程序；DMA：通常发完成中断，由 CPU 收尾
```

| 比较项 | 程序查询 | 中断 I/O | DMA |
|---|---|---|---|
| 就绪通知 | CPU 读状态端口 | 设备请求 CPU 响应 | 设备与 DMA 控制器协作 |
| 数据传送主体 | CPU 程序 | CPU 中断服务程序 | DMA 控制器控制硬件传送 |
| CPU 能否先做别的事 | 连续轮询时很难；定时轮询可穿插 | 等设备就绪时可以 | 数据搬运期间可以，但会争用主存/总线 |
| 一次操作结束 | CPU 检查、处理 | 服务程序处理并返回 | DMA 通常发完成中断，CPU 执行收尾 |
| 常见设备 | 简单/低速 | 键盘、打印机等零散事件 | 网卡、SSD、磁盘等批量数据 |

**题 19、38、51、54 的共同陷阱**：中断方式是“CPU 与设备工作可并行，数据传送时 CPU 参与”；DMA 在批量搬运时可以让 CPU 执行别的任务。选择适用设备看**持续速率、数据量、是否批量**，不是简单地看“设备是不是输出设备”。

## 三、中断：请求、响应、处理、返回

### 3.1 按时间顺序背，而非孤立背定义

```text
原程序执行
  -> 设备产生请求，接口/中断控制器暂存请求
  -> CPU 在可响应的时机检查：是否开中断？是否未被屏蔽？
  -> 中断响应（硬件）：关中断、保存断点 PC 及必要状态、取得服务入口
  -> 中断服务程序（软件）：保存通用寄存器等现场、处理中断、必要时开中断
  -> 恢复现场、中断返回（不是普通的“停机”）
```

- **发生**可以在一条指令执行中途，普通外中断的**响应**通常在当前指令执行完毕后。请求有效不等于立即响应；开中断但全被屏蔽，也不会响应相应请求。对照[题 12](./30ff0db6b0cdcd3c3b94e535607bb00f.jpg)、[题 41—42](./250786ca9e69fe946127759c37aa3b39.jpg)、[题 46、48、50](./f748d4c41307d809a4378978dff54a5b.jpg)。
- **外部中断**：键盘输入、定时器到时、网络数据到达、DMA 传送结束。**异常/陷入**：除零、缺页、执行断点指令。前者通常异步；后者关联当前指令。2020 的 [题 45](./250786ca9e69fe946127759c37aa3b39.jpg)、2025 的 [题 55](./434af53c3eda60fc4a8dc272cf56985b.jpg) 可并排重做。
- **NMI** 不受普通可屏蔽中断的开/关中断位控制；“可屏蔽中断有效就立刻响应”仍是错的（题 46）。题目中的“关中断”一般针对可屏蔽中断，不能用“所有中断都不响应”概括。
- **多重中断**允许服务程序在适当时刻开中断，以接受更高处理优先级的请求；“正在服务中断时 CPU 必定一直关中断”不成立。对照题 41、48 与单重中断的题 52。

### 3.2 谁来保护什么：题 15、18、27、34、37、42、52

| 阶段 | 常规考研模型中的工作 | 记忆点 |
|---|---|---|
| 响应（中断隐指令/硬件） | 关中断、保存返回用 PC/程序状态 PSW、获得服务程序入口 | 没有程序员写出的“关中断机器指令”才开始响应；硬件先做必要动作 |
| 服务程序（软件） | 保存/恢复所用通用寄存器，处理设备事件，可设置屏蔽字与开中断 | 通用寄存器**不是**默认全由中断隐指令保存 |
| 返回 | 恢复状态、回原程序继续 | 单重中断服务的结尾不是“系统停机” |

题 18 的关键硬件状态是 **PC 与 PSW**；题 42 与 52 考“不把通用寄存器保护说成中断隐指令”。具体处理器保存哪些状态可能有差异，做 408 选择题按题设及上述通用模型判断。

### 3.3 中断向量、向量地址：题 2、6

```text
中断类型/向量号 -> 中断向量表中的地址（向量地址）
                -> 该表项保存的服务程序入口地址（中断向量）
                -> CPU 按入口地址执行服务程序
```

照片里 **题 2 原选 B、红笔改 C**：向量地址不是服务程序入口地址，而是**存放该入口地址的存储单元地址**。一句话检验：某表项位于 0x1000，里面存 0x8000，则向量地址是 0x1000，服务程序入口是 0x8000。

### 3.4 响应优先级与处理优先级：题 17、35、52

- **响应优先级**：多个请求同时等待时先响应谁；通常由中断硬件排队逻辑决定。
- **处理优先级**：正在服务某源时允许谁来嵌套打断；可用中断屏蔽字调整。它会影响服务程序实际完成的次序，不要因此说固定的响应排队次序也被改写。
- 照片 [题 17](./c4cc1c219fcef41a363990afb3cac75b.jpg) 红笔纠正落在“多个服务程序执行完的次序”（D），题 52 考同一组概念。

**2011 真题题 35 的做法**：题设屏蔽字按 $M_4M_3M_2M_1M_0$ 排列，1 表示屏蔽该源；目标处理优先级为 $L_4>L_0>L_2>L_1>L_3$。正在服务 $L_1$，高于它的 $L_4,L_0,L_2$ 不能屏蔽（0）；自身 $L_1$ 和低于它的 $L_3$ 要屏蔽（1）。所以

```text
源： M4 M3 M2 M1 M0
值：  0  1  0  1  0  -> 01010（D）
```

先写目标处理顺序，再逐位填 0/1；不要直接按原来的“响应优先级”排序填屏蔽字。

## 四、DMA：一块数据怎样传

### 4.1 三段过程与通路

```text
准备：CPU/驱动设置方向、主存起址、传送量等，启动控制器
搬运：设备就绪 -> DMA 控制器申请并获得总线 -> 设备接口 <-> 主存
收尾：块传送完 -> DMA 完成中断 -> CPU 执行中断服务程序
```

题 23、44 考“整个 DMA 操作并非全由控制器做”；题 32 考初始化字段；题 29、53 考传送通路。记住**数据传送受 DMA 控制器控制**，不是“CPU 执行一段 DMA 搬运程序”。照片中题 29 把传送路径订正为经过 DMAC 的选项 B；题 53 红笔改 C，考的是**受控通路两端为设备接口和主存**。一个强调控制器参与，一个强调通路端点，不矛盾。

题 5 问“谁能产生 DMA 请求”：并不是所有高速外设都自动具备 DMA，也不是“想批量交换数据”就必然有 DMA 请求；要看是否**配有 DMA 接口/控制器**，照片红笔改为 B（仅 III）。题 31 将“启动一次 DMA”对应的传送量订正为**一个数据块**，而不是单个字节或单次总线宽度。

### 4.2 三个时刻一定分开：题 22、24、25、30、47

| 事件 | 请求什么 | 典型时机 | 后果 |
|---|---|---|---|
| 普通 I/O 中断请求 | CPU 执行服务程序 | 设备就绪/操作完成；通常指令结束后可响应 | 保存断点，转入服务程序 |
| DMA 总线请求 | 总线/主存使用权 | 设备缓冲准备好时，按总线/访存周期仲裁 | DMA 短暂占用所需周期，不必等整条指令结束 |
| DMA 完成中断 | CPU 做收尾 | 一整个 DMA 块完成后 | 按中断规则执行服务程序 |

**周期挪用**按一次数据传送挪用相应的**存取周期**，不是“整个块期间 CPU 都不能访存”。如果 CPU 正在用总线，就按题设仲裁；常见教材模型赋予 DMA 较高总线使用优先级，以免外设缓冲数据被覆盖。不要把它扩展成“DMA 在任何时刻比不可屏蔽中断更优先”：这是不同资源、不同响应时机的问题。

2020 真题 [题 47](./f748d4c41307d809a4378978dff54a5b.jpg)：512 B 的 DMA 块、32 bit = 4 B 缓冲，按每次缓冲准备好就请求总线，则有 $512/4=128$ **次总线请求**，但并非 128 次 CPU 完成中断；“整块传送过程中 CPU 不能访问主存”是错误说法（C）。

### 4.3 不要把三种“长度”混在一起

```text
一次总线搬运：例如 4 B
一个 DMA 块：  例如 512 B = 128 次 4 B 搬运
一次完成中断：一个块结束后通常通知一次
```

这正是题 31、47 和 2022 年磁盘综合题的共同套路。若题设一次搬运 8 B、一个扇区 512 B，则总线请求 $512/8=64$ 次；具体有无额外请求、一次占用几个周期，仍以题目给的传送机制为准。

## 五、计算题：先列“每秒事件次数”

设 CPU 主频 $f$（周期/秒）、每秒事件 $n$ 次、每次需 CPU 工作 $c$ 周期：

$$
\text{CPU 时间占比}=\frac{n\,c}{f}\times100\%.
$$

如果已给设备速率 $R$（字节/秒），每次传 $b$ 字节，先算 $n=R/b$；如果直接给“每隔 $T$ 秒一次”，则 $n=1/T$。**不要把 DMA 每次占用的总线周期当成 CPU 执行中断服务程序的周期**。

| 题目 | 代入 | 正确结论 |
|---|---|---|
| 2011 真题 [题 36](./acbafa365a6447fc57ab84457d0e5849.jpg) | 每秒至少 200 次查询、每次至少 500 周期；CPU $50\,\text{MHz}$ | 至少 $200\times500/(50\times10^6)=0.20\%$ |
| 2014 真题 [题 39](./acbafa365a6447fc57ab84457d0e5849.jpg) | 每 400 ns 一次中断，每次响应+处理 100 ns | 至少 $100/400=25\%$；“最多延迟 50 ns”是等待响应的许可，不等于每次 CPU 额外忙 50 ns |
| 2019 真题 [题 43](./250786ca9e69fe946127759c37aa3b39.jpg) | $50\,\text{kB/s}$，32 bit 缓冲即 4 B，每次中断 1000 周期，$1\,\text{GHz}$ | 按 $1\,\text{kB}=10^3\,\text{B}$，$n=50000/4=12500$ 次/秒；CPU 占比 $12500\times1000/10^9=1.25\%$ |

有“至少/最多”要保留方向：题 36 是每秒**至少**查 200 次、每次**至少**500 周期，因此求至少的占比；设备速率和处理次数随题设变化时不可机械套结论。

## 七、闭卷检查（先口答再翻答案）

1. 某设备在当前指令中途提出中断请求：CPU 什么时候可能响应？DMA 总线请求又在等什么？
2. 中断向量表某项在 0x1000，该项内容为 0x8000：向量地址、服务程序入口各是多少？
3. 正在服务 $L_1$，处理顺序是 $L_4>L_0>L_2>L_1>L_3$，1 表示屏蔽，求 $M_4M_3M_2M_1M_0$。
4. 512 B 的块，每次 DMA 传 4 B：总线请求多少次？为什么不能说完成中断 128 次？
5. 一个请求的响应/处理费 200 周期、CPU 为 100 MHz、每秒 1000 次请求，CPU 占比多少？

<details>
<summary>核对答案</summary>

1. 普通外中断通常待当前指令结束且开中断、未屏蔽等条件满足再响应；DMA 总线请求是在等待总线/主存使用权，通常不用等整条指令结束。
2. 向量地址 0x1000；服务程序入口 0x8000。
3. 01010。
4. $512/4=128$ 次；一个块多次占用总线，通常块完成后再发一次结束中断。
5. $1000\times200/(100\times10^6)=0.2\%$。

</details>
