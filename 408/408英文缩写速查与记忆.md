# 408 英文缩写速查表：全称、中文含义与记忆法

> 适用范围：计算机学科专业基础 408，四科分别为数据结构、计算机组成原理、操作系统、计算机网络。  
> 标记说明：★★★ 高频必会；★★ 常见；★ 了解即可。  
> 注意：有些缩写会跨科出现，例如 `FIFO`、`LRU`、`DMA`、`TLB`、`CRC`，复习时要放回具体语境理解。

## 六、怎么记：按 408 四科建立“缩写地图”

### 1. 数据结构：按“对象 + 操作”记

数据结构缩写大多围绕两件事：

- 存什么：`List`、`Stack`、`Queue`、`BT`、`BST`、`AVL`、`Graph`
- 怎么处理：`BFS`、`DFS`、`KMP`、`MST`、`Topo`、`ASL`

记忆句：

> 线性记进出，树图记遍历，查找记 ASL，排序记稳定和复杂度。

重点联想：

- `LIFO`：Last In First Out，最后进去的先出来，就是栈。
- `FIFO`：First In First Out，最先进来的先出去，就是队列。
- `BFS`：Breadth 是“宽度”，一层一层搜，所以用队列。
- `DFS`：Depth 是“深度”，一条路走到底，所以用栈或递归。
- `BST`：Search Tree，核心是“左小右大”。
- `AVL`：记成人名树，考点不是名字，而是平衡因子和四种旋转。

### 2. 组成原理：按“硬件路径”记

组成原理缩写可以按一次取指和执行过程串起来：

> `PC` 给地址，`MAR` 去访存，`MDR` 拿数据，`IR` 存指令，`CU` 发控制，`ALU` 做运算，`PSW` 记状态。

重点联想：

- `PC`：Program Counter，不是个人电脑，是“下一条指令地址”。
- `IR`：Instruction Register，当前指令。
- `MAR`：Address，所以是地址寄存器。
- `MDR`：Data，所以是数据寄存器。
- `CPI`：Cycle Per Instruction，越小通常越快。
- `MIPS`：Million Instructions Per Second，越大通常越快，但不同指令集间不能简单比较。
- `SRAM` 用于 Cache：Static，快但贵。
- `DRAM` 用于主存：Dynamic，需要刷新。

### 3. 操作系统：按“资源管理对象”记

操作系统缩写按四类资源归档：

- 处理机：`PCB`、`TCB`、`FCFS`、`SJF`、`RR`、`MLFQ`
- 内存：`MMU`、`TLB`、`PTE`、`FIFO`、`LRU`、`CLOCK`
- 文件：`FCB`、`FAT`、`inode`
- 设备：`I/O`、`DMA`、`SPOOLing`、`SSTF`、`SCAN`

记忆句：

> 进程看 PCB，调度看时间；内存看页表，置换看缺页；文件看 FCB，设备看 DMA。

重点联想：

- `PCB`：Process Control Block，进程控制块，是进程存在的唯一标志。
- `TCB`：Thread Control Block，线程控制块。
- `FCFS`：先来先服务，公平但可能平均等待时间大。
- `SJF`：短作业优先，平均等待时间小但可能饥饿。
- `RR`：Round Robin，轮流分时间片。
- `LRU`：Least Recently Used，最近最少用，抓住 Recently。
- `CLOCK`：像钟表指针一样转圈找可替换页。
- `SPOOLing`：把独占设备改造成共享效果，典型是打印缓冲。

### 4. 计算机网络：按“层次模型”记

网络缩写最适合按 OSI / TCP-IP 层次背：

| 层次 | 高频缩写 |
|---|---|
| 物理层 | `bps`、`baud`、`SNR`、`ASK`、`FSK`、`PSK`、`FDM`、`TDM` |
| 数据链路层 | `MAC`、`CRC`、`FCS`、`ARQ`、`GBN`、`SR`、`PPP`、`CSMA/CD` |
| 网络层 | `IP`、`ARP`、`ICMP`、`DHCP`、`NAT`、`CIDR`、`RIP`、`OSPF`、`BGP` |
| 传输层 | `TCP`、`UDP`、`ACK`、`SYN`、`FIN`、`RTT`、`RTO`、`MSS` |
| 应用层 | `DNS`、`HTTP`、`FTP`、`SMTP`、`POP3`、`IMAP` |

记忆句：

> 物理传比特，链路成帧，网络找路，传输管端到端，应用给用户服务。

重点联想：

- `ARP`：Address Resolution，地址解析，IP 找 MAC。
- `RARP`：Reverse ARP，反过来，MAC 找 IP。
- `ICMP`：Control Message，控制报文，Ping 常用。
- `DHCP`：Dynamic Host Configuration，动态配置主机网络参数。
- `NAT`：Address Translation，地址转换。
- `RIP`：Routing Information，路由信息协议，距离向量。
- `OSPF`：Open Shortest Path First，最短路径优先，链路状态。
- `BGP`：Border Gateway，边界网关，自治系统之间用。
- `TCP`：Transmission Control，可靠传输控制。
- `UDP`：User Datagram，用户数据报，简单快速不可靠。

### 最容易混淆的缩写

| 易混项 | 区分方法 |
|---|---|
| `MDR` vs `MAR` | `D` 是 Data，存数据；`A` 是 Address，存地址 |
| `PC` vs `IR` | `PC` 指向下一条；`IR` 保存当前这条 |
| `SRAM` vs `DRAM` | `S` 是 Static，快且贵；`D` 是 Dynamic，要刷新 |
| `FIFO` vs `LRU` | FIFO 看进入内存时间；LRU 看最近使用时间 |
| `SJF` vs `SRTF` | SJF 通常非抢占；SRTF 是抢占式最短剩余时间 |
| `FCB` vs `FAT` | FCB 是文件元数据；FAT 是磁盘块链接表 |
| `ARP` vs `RARP` | ARP：IP 到 MAC；RARP：MAC 到 IP |
| `RIP` vs `OSPF` | RIP 是距离向量；OSPF 是链路状态 |
| `TCP` vs `UDP` | TCP 可靠连接字节流；UDP 无连接报文 |
| `GBN` vs `SR` | GBN 回退重传一串；SR 选择性重传错误帧 |
