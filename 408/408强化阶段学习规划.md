# 408 强化阶段学习规划

> 适用对象：2027 考研 408，目标 120 分左右  
> 当前状态：前三本已完成第一轮，计网进行到网络层，准备完成计网后进入强化阶段  
> 核心目标：从“看懂知识点”切换到“稳定做对题、限时输出、能复盘失分原因”

## 一、阶段总目标

强化阶段不是重新听一遍课，而是建立四件事：

1. **知识体系闭环**：看到题目能迅速定位考点，而不是只记得在哪一章见过。
2. **选择题正确率稳定**：基础题和中档题尽量不丢分。
3. **大题套路成型**：数据结构算法题、计组计算题、OS 分析题、计网协议题都要有固定解题步骤。
4. **错题可复用**：错题不是收藏，而是能转化成下一次不再错的规则。

408 目标 120 分时，各科建议目标大致为：

| 科目 | 满分 | 目标 |
|---|---:|---:|
| 数据结构 | 45 | 37-40 |
| 计算机组成原理 | 45 | 35-38 |
| 操作系统 | 35 | 27-30 |
| 计算机网络 | 25 | 19-22 |

## 二、时间安排

以下安排按 2026 年 8 月中旬开始倒排。

### 0. 一轮收尾：8 月中旬 - 8 月底

目标：尽快完成计网第一轮，并把四科全部接上做题节奏。

任务：

- 完成计网网络层、运输层、应用层。
- 每章学完后立即做王道课后选择题，不要等全书结束再做。
- 标出所有错题，不必做复杂笔记，但必须写清楚错因。
- 用 2-3 天快速回顾四科目录，找出明显薄弱章。

计网重点：

- 子网划分、CIDR、路由表转发。
- IP 分片、ARP、ICMP。
- TCP 三次握手、四次挥手、可靠传输、滑动窗口、拥塞控制。
- DNS、HTTP、SMTP 等应用层基本流程。

### 1. 强化第一轮：9 月 - 10 月中旬

目标：完成王道课后题一刷，建立四科专题化做题能力。

建议顺序：

1. 数据结构
2. 计算机组成原理
3. 操作系统
4. 计算机网络

不建议完全按“重新听课”的方式推进。强化阶段应以做题为主，听课只用于补薄弱点。

每科处理方式：

| 科目 | 强化重点 |
|---|---|
| 数据结构 | 树、图、查找、排序、算法题表达 |
| 计组 | 数据表示、指令系统、CPU、流水线、Cache、虚拟存储、I/O |
| OS | 进程线程、同步互斥、调度、死锁、内存管理、文件系统 |
| 计网 | 网络层、运输层、TCP、IP、路由、应用层流程 |

### 2. 真题启动：9 月中旬开始

真题不要留到太晚。408 真题不仅是模拟卷，更是命题语言和考点权重的训练材料。

建议：

- 9 月中旬 - 9 月底：按章节做真题，不限时。
- 10 月开始：整套做真题，严格 180 分钟。
- 11 月中旬以后：近年真题作为高质量模拟使用。

真题使用顺序：

1. 先做章节真题，配合强化复习。
2. 再做早年整套真题，训练完整考试节奏。
3. 最后做近年真题，检测真实水平。

不要一上来就把最新年份真题做掉。

### 3. 强化第二轮：10 月中旬 - 11 月中旬

目标：二刷错题，补齐薄弱专题，开始形成稳定分数。

任务：

- 王道错题二刷。
- 真题错题精刷。
- 每周至少做 1-2 套完整 408 真题或模拟。
- 每科整理一份“考前可快速过”的薄弱点清单。

这一阶段要重点解决：

- 选择题反复错的概念。
- 计组计算题速度慢。
- OS 同步互斥、调度、内存管理题思路不稳定。
- 数据结构算法题写不完整。
- 计网协议流程混淆。

### 4. 冲刺阶段：11 月中旬 - 考前

目标：稳定输出，减少低级失误，保持手感。

任务：

- 近年真题整套限时完成。
- 回看真题错题和王道高频错题。
- 每 2-3 天做一组选择题保持题感。
- 每周保持数据结构算法题训练。
- 考前 10 天不再大规模开新资料。

冲刺阶段不要追求“补完所有不会的东西”，而是优先保证中高频内容稳定拿分。

## 三、每日学习结构

强化阶段每天建议按“复习 - 做题 - 复盘”三段走。

### 标准日安排

| 时间 | 内容 |
|---|---|
| 30-60 分钟 | 回顾当天专题知识点 |
| 2-3 小时 | 做王道课后题、真题或专题题 |
| 30-60 分钟 | 复盘错题 |
| 20-30 分钟 | 回看前一天错题 |

### 更推荐的执行方式

不要这样：

> 听完一章课，再集中刷很多题，错了以后只看答案。

应该这样：

> 先回顾框架，再做题，做错后定位错因，第二天重新做错题。

每天结束前问自己 3 个问题：

1. 今天哪个考点我以前以为会，其实不会？
2. 哪道题如果明天再做，我是否能独立做对？
3. 今天的错题属于知识漏洞、题型不熟、计算错误，还是审题问题？

## 四、错题整理方法

错题本不需要很精美，但必须能复用。

每道错题建议记录：

```text
题目来源：
所属科目：
所属章节：
错因类型：
正确思路：
下次避免规则：
```

错因类型建议分为：

| 类型 | 含义 |
|---|---|
| A | 知识点没掌握 |
| B | 概念混淆 |
| C | 公式或计算错误 |
| D | 审题错误 |
| E | 题型方法不熟 |
| F | 时间压力下失误 |

示例：

```text
题目来源：王道计组 Cache 选择题
所属科目：计组
所属章节：存储系统
错因类型：B
正确思路：组相联映射时先算块号，再算组号，不能直接用主存地址对 Cache 行数取模。
下次避免规则：凡是 Cache 映射题，固定按“块内地址 - 组号/行号 - 标记位”顺序拆地址。
```

## 五、各科强化建议

### 1. 数据结构

数据结构是最应该拿高分的科目。强化阶段要同时抓选择题和算法题。

重点：

- 树和二叉树。
- 图的遍历、最短路径、最小生成树、拓扑排序、关键路径。
- 查找和排序。
- 栈、队列、串、数组、广义表中的细节题。
- 算法题的伪代码表达。

算法题训练建议：

- 每周至少 3 道。
- 不只看思路，必须动手写。
- 写完后检查边界条件、时间复杂度、空间复杂度。
- 常用模板要熟，比如链表处理、树递归、图遍历、排序思想。

### 2. 计算机组成原理

计组是 408 冲 120 的关键。很多同学分数上不去，主要卡在计组。

重点：

- 原码、反码、补码、移码。
- 定点数和浮点数。
- 指令格式、寻址方式。
- CPU 数据通路和控制信号。
- 流水线性能计算。
- Cache 映射、命中率、平均访问时间。
- 虚拟存储、页表、TLB。
- I/O 方式、中断、DMA。

建议：

- 计组题不要只记结论，要会画过程。
- Cache、流水线、浮点数、指令系统要反复做。
- 对公式类题目整理固定模板。

### 3. 操作系统

OS 的题目看似概念多，但高频题型很集中。

重点：

- 进程、线程、处理机调度。
- 信号量、PV 操作、同步互斥。
- 死锁判断、银行家算法。
- 分页、分段、虚拟内存、页面置换。
- 文件系统、磁盘调度。

建议：

- 同步互斥题必须动手写信号量初值和 PV 位置。
- 调度题要画时间轴。
- 内存题要画页表、快表、地址结构。
- 死锁题要按资源分配表一步步推。

### 4. 计算机网络

计网分值相对少，但细节密集，适合通过反复刷题拿稳定分。

重点：

- OSI/TCP-IP 分层。
- 物理层和数据链路层基本概念。
- CSMA/CD、CSMA/CA、以太网、交换机。
- IP 地址、子网划分、CIDR、路由转发。
- ARP、ICMP、NAT。
- UDP、TCP。
- DNS、HTTP、电子邮件协议。

建议：

- 网络层和运输层优先级最高。
- TCP 可靠传输、拥塞控制、滑动窗口要画图理解。
- 子网划分每天少量练，直到不容易错。
- 应用层协议记功能、端口、流程，不要死背大段文字。

## 七、真题使用细则

真题每套至少做三件事：

1. 限时完成。
2. 精改。
3. 复盘到考点。

精改时不要只看分数，要统计：

| 指标 | 记录方式 |
|---|---|
| 总分 | 例如 105/150 |
| 选择题错题数 | 按科目统计 |
| 大题失分点 | 写清楚是步骤、公式、概念还是表达 |
| 超时位置 | 哪一科、哪类题花太久 |
| 下次改进 | 最多写 3 条 |

真题复盘模板：

```text
年份：
用时：
得分：
数据结构失分：
计组失分：
OS 失分：
计网失分：
最主要的 3 个问题：
下一套前必须解决的点：
```

## 九、最重要的执行原则

1. **从现在开始做题优先级高于听课。**
2. **错题必须二刷，否则错题整理没有意义。**
3. **真题 9 月中旬接触，10 月整套启动。**
4. **计组和数据结构决定上限，OS 和计网决定稳定性。**
5. **每周都要有一次阶段复盘，不能只往前赶进度。**
