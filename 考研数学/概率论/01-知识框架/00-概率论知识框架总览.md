## 全科主线

```text
随机现象
  -> 用事件描述结果
  -> 用概率描述事件可能性
  -> 用随机变量把结果数值化
  -> 用分布完整描述随机变量
  -> 用期望、方差等数字特征概括分布
  -> 用大数定律和中心极限定理研究大量重复试验
  -> 根据样本推断总体参数
  -> 参数估计与假设检验
```

## 做题时的通用检查顺序

1. 题目属于离散型、连续型，还是混合情形？
2. 已知的是分布函数、概率质量函数、密度，还是数字特征？
3. 目标是概率、分布、期望方差，还是总体参数？
4. 是否给出独立、同分布、正态总体等关键条件？
5. 连续型随机变量是否先明确积分区域？
6. 统计题是否先判断应使用正态、卡方、t 或 F 枢轴量？

## 必须形成的能力

- 能在集合语言、概率语言和随机变量语言之间转换。
- 能由联合分布得到边缘分布和条件分布。
- 能求随机变量函数的分布及数字特征。
- 能区分独立、不相关、互斥等概念。
- 能识别常见分布并熟记其期望、方差。
- 能正确标准化随机变量和统计量。
- 能根据题目条件选择估计或检验方法。

## 推荐复习方式

- **初学**：理解定义与公式来源，完成基础题。
- **强化**：按题型归纳入口，不按题目答案背步骤。
- **真题**：限时作答，并记录知识盲区与计算失误。
- **重做**：错题在第 2、7、21 天闭卷重做。
