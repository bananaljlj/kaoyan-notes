# 一、先导：实对称矩阵的性质

二次型的核心工具是**实对称矩阵的对角化**。二次型系数矩阵一定是对称矩阵，因此这一部分必须熟练。

## 1. 实对称矩阵的特征值都是实数

若 A 是实对称矩阵，则 A 的全部特征值都是实数。

### 例：由矩阵方程求行列式

若三阶实对称矩阵 A 满足 A³+A²+A+E=O，求 |A-2E|。

设 λ 是 A 的特征值，则 λ³+λ²+λ+1=0。分解：λ³+λ²+λ+1=(λ+1)(λ²+1)=0。

因为 A 是实对称矩阵，特征值必须是实数，所以 λ=±i 被排除，只能取 **λ=-1**。

于是 A 的三个特征值都是 -1，A-2E 的三个特征值都是 -1-2=-3，故 **|A-2E|=(-3)³=-27**。

> 易错：如果没有"实对称"条件，就不能直接排除复根 λ=±i。

---

## 2. 不同特征值对应的特征向量正交

设 A 为实对称矩阵，λ₁,λ₂ 是不同特征值，α₁,α₂ 是对应特征向量，则 λ₁≠λ₂ → α₁ᵀα₂=0。

即：**不同特征值对应的特征向量正交。**

注意：
- 不同特征值对应的特征向量自动正交；
- 相同特征值对应的特征向量不一定自动正交；
- 但在同一特征子空间中，可以通过正交化选出正交基。

---

## 3. 实对称矩阵一定可以正交对角化

若 A 是 n 阶实对称矩阵，则存在正交矩阵 Q，使得 Q⁻¹AQ=QᵀAQ=Λ，其中 Λ=diag(λ₁,λ₂,...,λₙ) 是由 A 的特征值构成的对角矩阵。

若 Q=(r₁,r₂,...,rₙ)，其中 rᵢ 是单位正交特征向量，则 QᵀAQ=Λ，并且 **A=QΛQᵀ**。

> 关键词：实对称矩阵、正交矩阵、单位正交特征向量、正交对角化。

---

# 二、二次型的定义与矩阵表示

## 1. 二次型定义

含 n 个变量的二次齐次多项式 f(x₁,x₂,...,xₙ) 称为二次型，一般写成：

f = a₁₁x₁² + a₂₂x₂² + ... + aₙₙxₙ² + 2a₁₂x₁x₂ + 2a₁₃x₁x₃ + ... + 2aₙ₋₁,ₙxₙ₋₁xₙ

令 x=(x₁,x₂,...,xₙ)ᵀ，A=(aᵢⱼ)，aᵢⱼ=aⱼᵢ，则 **f=xᵀAx**，其中 A 称为二次型的**系数矩阵**。

---

## 2. 交叉项系数要除以 2

由于 xᵀAx = Σᵢ aᵢᵢxᵢ² + 2Σᵢ₍ⱼ aᵢⱼxᵢxⱼ，所以若二次型中交叉项为 kxᵢxⱼ，则矩阵中 **aᵢⱼ=aⱼᵢ=k/2**。

### 例

f(x,y)=x²+xy+y² 对应矩阵是：

```
A = ⎡ 1    1/2 ⎤
    ⎣ 1/2  1   ⎦
```

而不是 [[1,1],[1,1]]。

---

## 3. 非对称矩阵出现在 xᵀMx 中怎么办？

如果题目给出 f=xᵀMx，但 M 不是对称矩阵，则二次型真正的系数矩阵是 **A=(M+Mᵀ)/2**，原因是 xᵀMx = xᵀ·((M+Mᵀ)/2)·x。

### 例

若 M = [[1,2,3],[4,5,6],[7,8,9]]，则 A=(M+Mᵀ)/2 为：

```
A = ⎡ 1  3  5 ⎤
    ⎢ 3  5  7 ⎥
    ⎣ 5  7  9 ⎦
```

---

# 三、合同变换、标准形与规范形

## 1. 二次型变换对应合同变换

设 f=xᵀAx，作可逆线性变换 x=Py（P 可逆），则 f=(Py)ᵀA(Py)=yᵀ(PᵀAP)y，新矩阵为 B=PᵀAP。

若存在可逆矩阵 P，使得 B=PᵀAP，则称 A 与 B **合同**。

---

## 2. 相似、合同、等价的区别

| 关系 | 形式 | 主要保持量 | 常见场景 |
|---|---|---|---|
| 等价 | PAQ=B | 秩 | 矩阵初等变换 |
| 相似 | P⁻¹AP=B | 特征值 | 矩阵对角化 |
| 合同 | PᵀAP=B | 秩、正负惯性指数 | 二次型变换 |

二次型中最重要的是：**x=Py → A 合同变换为 PᵀAP**，不是相似变换 P⁻¹AP。

当 P 是正交矩阵时，P⁻¹=Pᵀ，相似对角化和合同对角化形式上相同。

---

## 3. 标准形

经过可逆变换 x=Py，二次型化为只含平方项的形式 f=d₁y₁²+d₂y₂²+...+d_ry_r²，称为**标准形**。矩阵形式：PᵀAP=diag(d₁,...,d_r,0,...,0)。

---

## 4. 规范形

若标准形中非零系数只取 1 或 -1，即 f=z₁²+...+z_p²-z_{p+1}²-...-z_r²，则称为**规范形**。

- p：正惯性指数；q：负惯性指数；r=p+q：二次型的秩。

例如 f=y₁²+y₂²-2y₃² 是标准形，令 z₃=√2·y₃，则 f=z₁²+z₂²-z₃² 是规范形。

---

# 四、配方法化二次型为标准形

配方法本质上是通过可逆变量替换，把二次型逐步凑成平方和。

## 1. 配方法基本步骤

1. 先找一个平方项系数不为 0 的变量；
2. 把含该变量的项凑成一个完整平方；
3. 剩余部分继续配方；
4. 写出新变量与旧变量的关系；
5. 检查变量替换是否可逆；
6. 得到标准形，必要时缩放为规范形。

---

## 2. 二元例子

f(x,y)=x²+xy+y²。配方得 f=(x+y/2)²+(3/4)y²。

令 X=x+y/2，Y=y，则 f=X²+(3/4)Y²，反解为 x=X-Y/2，y=Y，变换矩阵：

```
P = ⎡ 1  -1/2 ⎤
    ⎣ 0   1   ⎦
```

---

## 3. 三元例子

设 f=x₁²+2x₂²+3x₃²+2x₁x₂+2x₁x₃+6x₂x₃，先按 x₁ 配方：

f=(x₁+x₂+x₃)²+(x₂+2x₃)²-2x₃²

令 y₁=x₁+x₂+x₃，y₂=x₂+2x₃，y₃=x₃，则 **标准形 f=y₁²+y₂²-2y₃²**，规范形 f=z₁²+z₂²-z₃²。

反解：x₃=y₃，x₂=y₂-2y₃，x₁=y₁-y₂+y₃，变换矩阵：

```
P = ⎡ 1  -1   1 ⎤
    ⎢ 0   1  -2 ⎥
    ⎣ 0   0   1 ⎦
```

---

## 4. 无平方项时的处理

例如 f=x₁x₂+x₂x₃=x₂(x₁+x₃)，令 x₁+x₃=z₁+z₂，x₂=z₁-z₂，x₃=z₃，则 f=(z₁-z₂)(z₁+z₂)=z₁²-z₂²，规范形为 **z₁²-z₂²**（p=1，q=1）。

---

# 五、正交变换法化二次型为标准形

## 1. 正交变换的意义

- 保持向量长度和夹角（几何上是旋转/反射）；
- 矩阵满足 QᵀQ=E，即 Q⁻¹=Qᵀ；
- **标准形系数 = 系数矩阵的特征值**（这是正交变换法的核心结论）。

---

## 2. 正交变换法步骤

给定 f=xᵀAx（A 对称）：

1. 写出系数矩阵 A；
2. 求特征方程 |λE-A|=0，得特征值 λᵢ；
3. 解 (λᵢE-A)x=0，得各特征向量；
4. **对重特征值对应的特征向量做 Schmidt 正交化**；
5. 将全部特征向量单位化；
6. 构造正交矩阵 Q=(r₁,r₂,...,rₙ)，则 QᵀAQ=diag(λ₁,...,λₙ)；
7. 在正交变换 x=Qy 下，**f=λ₁y₁²+λ₂y₂²+...+λₙyₙ²**。

---

## 3. 典型例题：正交变换化标准形

设 f(x₁,x₂,x₃)=-2x₁x₂+2x₁x₃+2x₂x₃，系数矩阵：

```
A = ⎡  0  -1  1 ⎤
    ⎢ -1   0  1 ⎥
    ⎣  1   1  0 ⎦
```

特征方程 |λE-A|=(λ-1)²(λ+2)=0，所以 λ₁=λ₂=1，λ₃=-2。

可取单位正交特征向量 r₁=(1/√2)(1,-1,0)ᵀ，r₂=(1/√6)(1,1,2)ᵀ，r₃=(1/√3)(1,1,-1)ᵀ，构造 Q=(r₁,r₂,r₃)，则：

- 正交变换 x=Qy 下，**标准形 f=y₁²+y₂²-2y₃²**；
- 规范形 f=z₁²+z₂²-z₃²（令 z₃=√2·y₃）。

---

## 4. 已知正交标准形反求原二次型

若已知 x=Qy 使得 f=yᵀΛy，则原系数矩阵 **A=QΛQᵀ**，展开即得 f=xᵀAx。

### 例

已知标准形 f=y₁²+y₂²-2y₃²，Q 的第三列为 r₃=(1/√3)(-1,1,1)ᵀ（对应 λ₃=-2）。

补出与 r₃ 正交的两个单位向量 r₁=(1/√2)(1,1,0)ᵀ，r₂=(1/√6)(-1,1,-2)ᵀ，构造 Q=(r₁,r₂,r₃)，则 A=QΛQᵀ 为：

```
A = ⎡  0   1   1 ⎤
    ⎢  1   0  -1 ⎥
    ⎣  1  -1   0 ⎦
```

所以原二次型为 **f=2x₁x₂+2x₁x₃-2x₂x₃**。

---

# 六、正定与负定

## 1. 正定定义

若对任意 x≠0 都有 xᵀAx>0，则 f 为**正定二次型**，A 为**正定矩阵**。

## 2. 负定定义

若对任意 x≠0 都有 xᵀAx<0，则 A 为**负定矩阵**。

---

## 3. 正定的充要条件（五个等价形式）

1. 对任意 x≠0，xᵀAx>0；
2. 标准形系数全为正；
3. 规范形为 y₁²+y₂²+...+yₙ²；
4. 全部特征值大于零：λᵢ>0；
5. **顺序主子式全大于零**：Δ₁>0，Δ₂>0，...，Δₙ>0。

三阶时具体为：a₁₁>0，det([[a₁₁,a₁₂],[a₂₁,a₂₂]])>0，|A|>0。

---

## 4. 负定的充要条件

A 负定 ⟺ -A 正定，等价于 (-1)^r·Δᵣ>0（r=1,2,...,n）。三阶时：Δ₁<0，Δ₂>0，Δ₃<0。

---

## 5. 平方和不一定正定

若 f=l₁²+l₂²+...+lₖ²，只能说 f≥0（半正定）。正定还需 f=0 ⟹ x=0，即方程组 l₁=l₂=...=lₖ=0 只有零解。

### 例

f=(x₁+x₂)²+(x₂+x₃)²+(x₁+tx₃)² 正定的条件：方程组

```
  x₁+x₂=0
  x₂+x₃=0
  x₁+tx₃=0
```

只有零解，即系数矩阵行列式不为零：

```
| 1  1  0 |
| 0  1  1 | = t+1 ≠ 0
| 1  0  t |
```

所以 **t≠-1**。

# 七、典型题型与解题套路

## 题型 1：写二次型的矩阵

- 平方项系数放对角线；
- 交叉项 kxᵢxⱼ 对应 aᵢⱼ=aⱼᵢ=k/2；
- 保证矩阵对称。

## 题型 2：由 xᵀMx 写二次型矩阵

M 对称时取 A=M；M 不对称时取 A=(M+Mᵀ)/2。

## 题型 3：配方法化标准形

适用：题目不要求正交变换，或二次型结构明显。套路：原二次型 → 凑平方 → 可逆变量替换 → 标准形 → 规范形。必须检查变换矩阵行列式≠0。

## 题型 4：正交变换化标准形

适用：题目要求正交变换或需要几何解释。套路：A → 求λᵢ → 求αᵢ → 正交单位化 → Q → QᵀAQ=Λ → 写标准形。

## 题型 5：已知标准形反求原二次型

已知 x=Qy，f=yᵀΛy，则 **A=QΛQᵀ**，展开 f=xᵀAx。

## 题型 6：判断正定/负定

| 方法 | 适用场景 |
|---|---|
| 特征值法（λᵢ>0）| 矩阵特征值容易求 |
| 顺序主子式法（Δᵣ>0）| 一般情况，最常用 |
| 定义法（验证零解）| 平方和形式 |

## 题型 7：由平方线性式快速写矩阵

若 l=aᵀx，则 l²=(aᵀx)²=xᵀ(aaᵀ)x。多个平方线性式之和：A=Σ aᵢaᵢᵀ。

例：l=x₁+2x₂-x₃，a=(1,2,-1)ᵀ，则 l²=xᵀ·aaᵀ·x，其中：

```
aaᵀ = ⎡  1   2  -1 ⎤
      ⎢  2   4  -2 ⎥
      ⎣ -1  -2   1 ⎦
```

# 八、高频易错点总结

1. **交叉项系数忘记除以 2**：xᵢxⱼ 的系数是 k → aᵢⱼ=k/2，不是 k。

2. **把非对称矩阵直接当二次型矩阵**：必须取 A=(M+Mᵀ)/2。

3. **合同与相似混淆**：x=Py 后矩阵变为 PᵀAP（合同），不是 P⁻¹AP（相似）。

4. **求正交矩阵时忘记单位化**：列向量必须两两正交且长度为 1。

5. **重特征值的特征向量没有正交化**：同一特征子空间内的多个特征向量需做 Schmidt 正交化。

6. **交换 Q 的列后忘记交换特征值顺序**：Q 的列顺序与 Λ 对角元素顺序必须一致。

7. **改变特征向量符号不能改变特征值符号**：Aα=λα ⟹ A(-α)=λ(-α)，特征值不变。

8. **用不可逆变量替换**：若新变量线性相关（如 y₃=y₁+y₂），变换不可逆，不能用作合法化标准形的变换。

9. **平方和就认为正定**：平方和只保证 f≥0，正定还需 f=0 ⟹ x=0。

10. **标准形与规范形混淆**：标准形 y₁²+y₂²-2y₃²（系数可以是任意实数）；规范形 z₁²+z₂²-z₃²（系数只有±1）。

# 九、考前速记清单

## 核心公式

- f=xᵀAx，Aᵀ=A；
- x=Py → f=yᵀ(PᵀAP)y；
- A 合同 B ⟺ B=PᵀAP；
- QᵀAQ=Λ，QᵀQ=E（正交对角化）；
- 正交变换下：f=λ₁y₁²+...+λₙyₙ²；
- A=QΛQᵀ（已知 Q 和 Λ 反求 A）；
- A_二次型=(M+Mᵀ)/2（M 非对称时）；
- (aᵀx)²=xᵀ(aaᵀ)x。

## 惯性指数

规范形 f=y₁²+...+y_p²-y_{p+1}²-...-y_r²：p=正惯性指数，q=负惯性指数，r=p+q=秩。

## 正定/负定

- A 正定 ⟺ λᵢ>0 ⟺ Δ₁>0，Δ₂>0，...，Δₙ>0；
- A 负定 ⟺ λᵢ<0 ⟺ (-1)^r·Δᵣ>0；三阶负定：Δ₁<0，Δ₂>0，Δ₃<0。

## 做题路线选择

| 题目要求 | 推荐方法 |
|---|---|
| 正交变换化标准形 | 特征值 → 特征向量 → Schmidt → 单位化 → Q |
| 化标准形（不要求正交）| 配方法（更快）|
| 规范形 | 先化标准形，再把非零系数缩放为±1 |
| 正定/负定判断 | 优先顺序主子式；特征值容易时用特征值法；平方和用零解法 |

## 一句话理解二次型

二次型就是"一个对称矩阵 A 通过 xᵀAx 表示出来的函数"；化标准形就是"通过可逆变量替换把 A 合同对角化"；正交变换法就是"利用实对称矩阵可以被正交对角化，标准形系数就是特征值"。
